隐私政策

哪些信息留在设备上，哪些连接会访问网络，以及你可以做出的选择。

适用范围与运营者

本政策适用于由李英杰提供的 AirAtlas iOS 网络电台 App，以及本网站的隐私与支持页面。当前首发版本提供电台发现、搜索、播放、收藏、收听历史和自定义电台功能，不提供账号注册、广告 SDK、音频录制、字幕转写、翻译或云端同步。

隐私咨询与相关请求可发送至 911306393@qq.com。

保存在设备上的信息

App 在本地保存收藏、最近收听、自定义电台地址、显示地区、外观偏好、目录缓存和生成的封面缓存。AirAtlas 当前没有接收这些资料的自建业务服务器。自定义地址可能含访问参数，请仅保存你有权使用和信任的地址。

设备上的数据可能随你的系统设置包含在 Apple 的设备备份中；这不等于 AirAtlas 提供跨设备云同步。

联网时的信息处理

  • 目录与搜索：查询发送至 Radio Browser 的目录节点，可包含搜索文字、国家、分类、分页参数和 App 版本标识。节点会接收到连接 IP 地址及正常请求信息。
  • 播放：App 直接连接所选电台或其流媒体服务商。服务方会接收到 IP 地址与正常连接信息。直播可能含由广播机构提供的广告，AirAtlas 不承诺移除这些节目内容。
  • 收听点击：电台开始播放时，App 会尽力向 Radio Browser 发送一次对应电台的点击请求，用于目录收听统计。
  • 台标与外部网页：加载目录提供的电台图片会访问相应图片服务；主动打开电台官网、地图或系统分享时，后续处理遵循相应服务的规则。

第三方是否保留服务器日志及其保留时间由服务方决定。不能将“本地保存资料库”理解为“第三方完全不接收网络信息”。目录服务说明见 Radio Browser。

权限、分析与音频

当前发行版本不使用麦克风，不录制或上传广播音频进行识别，不集成广告或跨 App 跟踪 SDK，也不向 AirAtlas 自建分析服务发送使用分析数据。后台音频权限用于在切换 App 或锁屏时继续播放。

开发阶段的字幕与歌曲识别实验入口不会包含在当前 Release 发行包中。未来如启用这些功能，将重新说明实际处理方式与所需权限。

保留、清理与用户选择

你可以在 App 设置中清理目录缓存和收听历史，移除收藏或删除手动添加的电台。清理历史不自动删除收藏。生成的封面属于可重新生成的缓存，会按容量规则淘汰；系统也可能清理缓存。

卸载 App 通常会移除其设备本地数据；从系统备份恢复可能恢复备份内的数据。第三方服务器日志不受 App 的本地清理按钮控制。如需咨询资料处理、访问、更正或删除事宜，可联系运营者；若请求涉及广播服务方，我们会说明其独立处理范围。

本网站与托管

本网站使用静态页面，不嵌入分析脚本、广告、第三方字体或在线表单。点击邮箱链接会交由你的邮件客户端处理，发送的内容由邮件服务提供商处理，运营者会收到你主动发送的信息。

部署至 GitHub Pages 后，GitHub 将作为托管服务商处理访问请求。其网络日志等处理以 GitHub 隐私声明为准。静态网站不意味着托管服务商不会接收 IP 地址。

未成年人

本 App 面向一般用户，并非专为儿童设计。电台是第三方实时内容，内容和适龄程度可能变化；未成年人应在监护人指导下使用。我们不会将电台目录的存在视作对全部节目的适龄保证。
