适用范围与运营者

本政策适用于由 LIYINGJIE 提供的 AirAtlas iPhone、iPad App 及本网站。AirAtlas 是用户自行导入电台的播放工具，支持导入 JSON 文件、手动添加直播地址、搜索与整理个人资料库、收藏、最近播放和歌曲识别。使用这些功能时的信息处理如下。

设备上的资料

导入文件中的电台名称、直播地址、国家或地区、语言、分类、封面地址及可选坐标会在设备上解析和保存，用于浏览、搜索和播放。导入会替换当前设备的目录，收藏、手动添加的电台和历史记录会保留。完整导入目录仅保存在本设备，不参与 App 的 iCloud 同步；其他设备需要分别导入。

收藏、手动添加的地址、最近播放、识曲记录、收听时长、目标和外观偏好也会保存在设备上。封面等可重新获取的资源使用本地缓存。地址可能包含私密参数，请谨慎选择文件和链接，不要在反馈中发送密码或完整访问令牌。

个人 iCloud 同步

iCloud 可用时，App 支持的个人资料库、识曲记录、收听统计和偏好会通过 Apple CloudKit 私有数据库同步到同一 iCloud 账户的设备。对这些个人记录的删除和清空也会同步，完成时间受网络与 Apple 服务调度影响。导入目录的替换或清空仅影响当前设备，不会清空其他设备的导入目录。

完整导入目录、封面缓存、音频及 GPS 位置不通过此功能同步。可在系统设置中管理 App 的 iCloud 访问。同步与设备系统备份是不同功能。

播放与网络连接

导入文件的解析以及对导入资料的浏览、搜索在设备上进行。选择播放后，App 连接文件或手动添加地址所指向的音频服务；加载封面会连接相应图片地址。这些提供方会收到 IP 地址及正常网络请求信息，并按各自规则处理日志。AirAtlas 不使用自建业务服务器接收你的完整导入文件或个人资料库。

直播播放需要网络，可能产生移动数据费用。打开第三方网站、音乐 App、商店或分享功能后，适用相应服务的数据处理规则。

音频与歌曲识别

App 不使用麦克风，也不提供面向用户的广播录音、音频下载或离线节目保存功能。播放需要临时缓冲；主动发起歌曲识别时，App 会处理当前音频并将音频指纹发送给 Apple 的 Shazam 服务。该服务接收指纹与正常网络信息，识别结果可能不准确或无法匹配。

识曲记录可在资料库管理，并在 iCloud 可用时同步。字幕和翻译当前暂未开放。App 不集成广告或跨 App 跟踪 SDK，不向 AirAtlas 自建分析服务发送使用分析数据。

地区信息与位置

打开地区信息时，可根据导入资料中的国家、地区或坐标获取天气、时区与维基百科内容。网络提供方接收查询参数、IP 地址和正常连接信息；电台坐标不等同于你的 GPS 位置。相关数据与技术许可见 App 的致谢页面。

只有点击当前位置功能时才申请使用期间的位置权限。位置在设备上用于寻找附近电台和移动地球视角，不用于后台追踪，也不会上传至 AirAtlas 自建服务器。可在系统设置撤销权限。

保留、清理与选择

可在“设置 → 应用设置”导入电台或清空当前设备的导入目录。清空目录保留收藏、手动添加的电台与历史记录；当前收听可继续。个人记录可在资料库分别管理，支持同步的删除操作会传播到其他设备。缓存可在存储设置中清理，系统也可能回收缓存。

卸载通常移除本地 App 数据，但不会自动删除已同步至 iCloud 的资料。系统备份恢复或再次同步可能恢复部分个人记录。App 的本地清理不影响第三方服务器日志。如需咨询资料访问、更正或删除，请联系运营者。

网站、联系与托管

本网站使用静态页面，不嵌入分析脚本、广告、第三方字体或在线表单。邮箱链接交由你的邮件客户端处理；你主动联系时，我们会收到你选择发送的内容，仅用于处理该事项，不自动订阅营销邮件。

GitHub Pages 托管会按 GitHub 隐私声明处理访问请求，包括 IP 地址等正常网络信息。

未成年人使用

AirAtlas 面向一般用户，并非专门为儿童设计。用户导入的链接及实时音频内容由相应提供方控制，家长或监护人应协助未成年人选择适合的内容。
