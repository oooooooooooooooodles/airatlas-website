隐私政策

哪些信息留在设备上，哪些连接会访问网络，以及你可以做出的选择。

适用范围与运营者

本政策适用于由LIYINGJIE提供的 AirAtlas iOS 网络电台 App，以及本网站的隐私与支持页面。当前首发版本提供电台发现、搜索、播放、收藏、收听历史和自定义电台功能，不提供账号注册、广告 SDK 或音频录制。iCloud 可用时会自动同步个人电台资料，可在系统设置中管理 App 的 iCloud 访问。歌曲识别由用户主动开启，受直播格式和服务可用性限制；字幕与翻译当前暂未开放。

隐私咨询与相关请求可发送至 911306393@qq.com。

保存在设备上的信息

App 在本地保存收藏、最近收听、自定义电台地址、累计收听时长、显示地区、外观偏好、目录缓存和生成的封面缓存。AirAtlas 当前没有接收这些资料的自建业务服务器。自定义地址可能含访问参数，请仅保存你有权使用和信任的地址。

iCloud 可用时，收藏、自定义电台、最近播放、识曲记录、每日及累计收听时长、收听目标和地区、外观设置会存入你个人的 Apple CloudKit 私有数据库。目录缓存、音频、位置、字幕和转写内容不上传。删除和清空操作也会在同步可用时传播至其他设备，完成时间受网络与 Apple 服务调度影响。设备系统备份与这项同步相互独立。

联网时的信息处理

  • 目录与搜索：查询发送至 Radio Browser 的目录节点，可包含搜索文字、国家、分类、分页参数和 App 版本标识。节点会接收到连接 IP 地址及正常请求信息。
  • 播放：App 直接连接所选电台或其流媒体服务商。服务方会接收到 IP 地址与正常连接信息。直播可能含由广播机构提供的广告，AirAtlas 不承诺移除这些节目内容。
  • 收听点击：电台开始播放时，App 会尽力向 Radio Browser 发送一次对应电台的点击请求，用于目录收听统计。
  • 台标与外部网页：加载目录提供的电台图片会访问相应图片服务；主动打开电台官网、地图或系统分享时，后续处理遵循相应服务的规则。

第三方是否保留服务器日志及其保留时间由服务方决定。不能将“本地保存资料库”理解为“第三方完全不接收网络信息”。目录服务说明见 Radio Browser。

地区信息与外部服务

打开电台地区信息时，App 可使用电台地区、国家或坐标查询天气、时区和维基百科内容。这些服务会收到查询参数、IP 地址及正常网络信息；电台坐标并不等于你的 GPS 位置。打开第三方音乐平台或其商店页面后，适用相应平台的数据处理规则。

权限、分析与音频

App 不使用麦克风、不保存广播录音、不集成广告或跨 App 跟踪 SDK，也不向 AirAtlas 自建分析服务发送使用分析数据。后台音频权限用于在切换 App 或锁屏时继续播放。

开启歌曲识别时，App 额外连接当前电台并在内存中分析音频，将生成的音频指纹发送至 Apple 的 Shazam 服务进行匹配；Shazam 会接收到指纹及正常网络连接信息。识曲记录包含歌曲、电台信息和识别时间，可在资料库删除，并随 iCloud 同步。识别可能产生额外流量。字幕与翻译当前暂未开放，不会因普通收听而启动语音转写或翻译。第三方服务遵循其各自条款及隐私政策。

可选的当前位置

仅在你点击地球定位按钮后，App 才请求使用期间的位置权限，并进行一次定位。支持大致位置。坐标仅在设备内存中用于寻找最近的电台并移动地球视角，不写入历史或缓存、不上传至 AirAtlas 或电台目录，也不用于后台追踪。可在系统设置中撤销权限。

保留、清理与用户选择

你可以在 App 设置中清理目录缓存和收听历史，移除收藏或删除手动添加的电台。清理历史不自动删除收藏。生成的封面属于可重新生成的缓存，会按容量规则淘汰；系统也可能清理缓存。

卸载 App 通常会移除其设备本地数据；从系统备份恢复可能恢复备份内的数据。第三方服务器日志不受 App 的本地清理按钮控制。如需咨询资料处理、访问、更正或删除事宜，可联系运营者；若请求涉及广播服务方，我们会说明其独立处理范围。

本网站与托管

本网站使用静态页面，不嵌入分析脚本、广告、第三方字体或在线表单。点击邮箱链接会交由你的邮件客户端处理，发送的内容由邮件服务提供商处理，运营者会收到你主动发送的信息。

部署至 GitHub Pages 后，GitHub 将作为托管服务商处理访问请求。其网络日志等处理以 GitHub 隐私声明为准。静态网站不意味着托管服务商不会接收 IP 地址。

未成年人

本 App 面向一般用户，并非专为儿童设计。电台是第三方实时内容，内容和适龄程度可能变化；未成年人应在监护人指导下使用。我们不会将电台目录的存在视作对全部节目的适龄保证。
