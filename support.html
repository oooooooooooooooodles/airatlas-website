你可能想了解

如何导入电台？

打开设置 → 应用设置 → 导入电台，选择 UTF-8 JSON 文件并确认导入。也可以在资料库的我的电台中手动添加直播地址。请仅使用你有权访问的文件和地址。

导入文件需要什么格式？

JSON 根节点为数组。每条电台包含 stationuuid（唯一字符串）、name 和 url 或 url_resolved（HTTP/HTTPS 地址）。国家、语言、分类、封面和坐标为可选资料。支持不超过 150 MB、100,000 条的文件，导入前会显示有效条目数量。

电台为什么无法播放？

直播地址可能失效、改址或限制访问。请检查文件中的地址、网络及提供方条件；更新文件后可重新导入。

清空目录会删除收藏吗？

不会。清空当前设备的导入目录会保留收藏、手动添加的电台及历史，当前收听可继续。完整目录需在每台设备分别导入；支持同步的个人资料可通过 iCloud 同步。

能否离线收听或识别歌曲？

直播需要联网，已保存的电台资料可供离线浏览。播放器提供可选的歌曲识别，结果受音频及服务可用性影响。字幕和翻译目前暂未开放。

工具定位、内容权利与反馈

AirAtlas 是由用户自行导入电台的播放与资料库管理工具。文件和手动添加的地址由用户选择，播放时直接连接相应的音频服务。导入的资料用于个人浏览与收听，不会由此公开发布给其他用户。

请遵守内容提供方的条款与访问限制。导入、收藏或生成封面不授予节目、音乐、台标及其他素材的使用许可。App 不提供广播下载或绕过访问控制的功能。

权利人或授权代表可通过上述邮箱反馈问题。请提供相关名称或地址、涉及的内容、权利依据及希望采取的措施，不要发送密码或私密令牌。我们会核查并在可控制范围内处理；来源服务的修改需要其提供方处理。详见 使用条款。
