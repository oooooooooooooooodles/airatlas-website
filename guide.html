如何在 iPhone／iPad 导入

  1. 1

    保存下载文件

    点击下载，将 stations.json 保存到“文件”App 的“下载项”，无需解压。若在微信等内置浏览器中无法下载，请用 Safari 打开本页。

  2. 2

    确认文件已保存

    在“文件”App → 下载项中找到 stations.json，等待下载完成。如果 Safari 显示 JSON 文字，请点击分享 → 存储到“文件”。

  3. 3

    在 AirAtlas 中导入

    打开 AirAtlas → 设置 → 应用设置 → 导入电台，选择 stations.json。等待预览出现后，点击“导入并替换目录”。大文件首次处理需要一些时间。

  4. 4

    开始浏览和收听

    在“现在就听”浏览推荐，或通过搜索分类、“发现”的地球寻找电台。点击电台播放，使用五角星加入收藏；可在设置中切换国家或地区。

导入前请了解

  • 确认导入会替换本设备已导入的目录。需要保留原目录时，请先在设置中导出备份。收藏、手动添加的电台和历史记录会保留。
  • iPhone 与 iPad 需分别导入文件。完整目录不通过 iCloud 整体同步，支持同步的个人资料库数据单独处理。
  • JSON 文件仅含电台资料和链接，不含音频或内嵌封面。目录资料来自公共领域社区数据；这不代表获得节目、台标或商标的使用许可。
  • 这是有日期的目录快照，不是实时可用性保证。不完整条目可能被跳过，部分电台可能停播或受访问限制。播放需要联网，请遵守来源服务的使用条件。

常见问题

下载后打开的是一页文字？

JSON 是资料文件。请将文件存到“文件”App，再从 AirAtlas 的“导入电台”入口选择它，不需要复制粘贴里面的文字。

导入数量变少，或部分电台没有声音？

不完整或重复的记录会被跳过。直播地址也可能改址、失效或限制访问；可以尝试其他电台，或重新导入更新后的文件。

下载后可以离线收听吗？

不能。目录是电台资料，直播音频仍需要网络连接。
